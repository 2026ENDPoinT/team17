# 화면 코드 작성 가이드

이 문서는 `web/`의 코드를 구현하거나 수정할 때 따르는 사용자 요청 규칙이다.

## 1. 요청한 함수 중심으로 구현한다

- 사용자가 요구한 함수를 중심으로, 요청한 범위만 구현한다.
- 편의나 구조 개선을 위한 보조 함수를 임의로 추가하지 않는다.
- 부가적인 함수가 필요하면 그 함수의 역할과 필요한 이유를 간략히 설명하고, 사용자에게 물어본 뒤 추가한다.

## 2. 모든 함수에 역할 주석을 단다

- 코드를 작성한 뒤, 작성하거나 수정한 모든 함수에 무슨 일을 하는지 한국어 주석을 단다.
- 일반 함수뿐 아니라 변수에 담은 화살표 함수와 이벤트 콜백에도 적용한다.
- 주석은 함수 선언이나 콜백을 등록하는 코드 바로 위에 짧게 적는다.

## 3. 구현 후 함수와 실행 흐름을 설명한다

- 구현하거나 수정한 각 함수가 어떤 작업을 하는지 간략히 정리한다.
- 어떤 입력을 받아 무엇을 반환하거나 화면에서 무엇을 바꾸는지 설명한다.
- 함수들이 어떤 순서로 호출되고 데이터가 어떻게 전달되는지 전체 흐름을 정리한다.
- JavaScript를 처음 접하는 사용자가 이해할 수 있는 쉬운 표현을 쓴다.
- 설명은 핵심 위주로 간결하게 작성하고, 예시는 필요한 경우 하나 정도만 든다.

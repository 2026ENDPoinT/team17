# 화면 디자인 규칙

현재 메인·상세 화면과 필터 팝업에 적용한 기준이다.
화면 구성·동작은 [화면 요구사항](screen-requirements.md), 코드 작성 규칙은 [코딩 가이드](coding-guide.md)를 따른다.

## 색상

### 메인 화면의 현재 색 역할

메인은 배경(`--color-background`)·아이보리 패널(`--color-panel`)·따뜻한 흰색 카드와 입력(`--color-content`, `#FFFDF9`)으로 나눈다. 기본 윤곽선은 옅은 회갈색(`--color-border`, `#D5CEC5`)이다. 필터 선택·초기화 버튼과 적용된 필터는 밤색 바탕·밝은 글씨로 표시한다. 카드·드롭다운 호버는 연한 베이지 배경과 밤색 테두리이며, 버튼의 호버는 진한 밤색이다. 아래의 이전 메인 배색 설명보다 이 절을 우선한다. 팝업 배색은 유지한다.

공통 색상은 [theme.css](../theme.css)의 CSS 변수로 관리한다. 화면별 CSS에서는 색상 값을 직접 쓰지 않고 변수를 사용한다.

| 변수 | 색상 | 용도 |
|---|---|---|
| `--color-background` | 웜그레이 `#E8E4DE` | 전체 배경, 팝업 뒤 배경 |
| `--color-panel` | 옅은 아이보리 `#F7F5EF` | 메인의 선택 필터 글씨, 팝업 본문·상단·하단 |
| `--color-sand` | 샌드 베이지 `#DED0BE` | 메인 카드·버튼·드롭다운, 팝업의 선택된 옵션 |
| `--color-surface` | 크림색 `#F1EADF` | 메인 제목·목록·정렬·필터 패널, 팝업 버튼의 기본 배경 |
| `--color-text` | 고동색 `#352820` | 제목·본문·버튼 글씨, 팝업 외곽선 |
| `--color-secondary` | 연한 베이지 `#EDE2D4` | 기본 테두리, 호버 배경, 스크롤 막대 |
| `--color-primary` | 밤색 `#8B5E3C` | 호버 테두리, 포커스 표시, 선택 표시 |

`--color-muted`와 `--color-primary-hover`는 팔레트에 남아 있는 보조 명도이며 현재 메인·팝업에서는 사용하지 않는다.
팝업 뒤 배경은 웜그레이를 불투명도 80%로 덮는다.

## 패널과 배치

- 상세는 메인과 같은 바깥 너비 계산과 위아래 32px 여백을 사용한다. 좌우는 1:1, 간격은 24px다. 검수 배지는 별도 상단 행의 둥근 사각형으로 두며 아래 좌우 박스의 위 경계를 맞춘다. 이동 버튼은 내용 너비로 가운데 배치한다.
- 상세의 배경·패널·조건 카드는 메인의 배경·패널·카드 색을 따른다. 글씨와 기본 경계도 메인과 같으며, 버튼과 원문 토글은 밤색 바탕·밝은 글씨와 진한 밤색 호버를 사용한다.
- 상세 이동 버튼은 왼쪽 하단에 유지하고 핵심 정보 내부와 오른쪽 메모를 각각 스크롤한다. 핵심 정보 스크롤은 메인과 같은 안쪽 여백 12px·폭 8px·투명 트랙·둥근 막대를 사용한다. 카테고리는 밤색 배지, 요약은 큰 글씨와 밤색 왼쪽 세로선으로 강조한다.
- 메인은 중앙 정렬하며 바깥 위아래 여백은 32px, 좌우는 최소 40px로 둔다. 화면이 넓으면 좌우 여백도 늘린다.
- 상단 제목 바는 높이 64px로 양쪽 영역 전체 너비를 차지한다. 메인·즐겨찾기 모두 제목과 현재 목록 건수(`총 N건`)를 한 줄로 표시한다.
- 목록 건수는 버튼과 같은 밤색 배경·밤색 테두리·밝은 글씨·12px 둥근 모서리의 배지 안에 굵은 글씨로 표시한다. 클릭 동작은 없다.
- 아래 왼쪽 목록은 남은 화면 높이에 맞춰 정사각형에 가까운 비율로 배치한다. 오른쪽 설정 너비는 360px, 영역 간격은 24px다.
- 메인 패널 모서리는 24px, 기본 테두리는 고동색 1px다.
- 팝업은 최대 너비 960px, 화면 가장자리와 최소 32px를 띄운다. 외곽 모서리는 12px, 고동색 테두리는 2px다.
- 학과 선택 영역은 단과대학 제목이 한 행을 차지하고 소속 학과 버튼을 그 아래 3열로 배치한다. `학과 제한 없음` 버튼은 단과대학 제목들보다 위에 둔다.
- 팝업의 상단 제목과 하단 버튼은 고정하고 본문만 스크롤한다. 내부 그룹은 배경 없이 간격과 구분선으로 나눈다.
- 팝업 본문은 안내문 → 모집 상태 → 유형 → 학년 → 학과 순서다. 안내문의 학과 제한 없음 설명 뒤에서 줄을 나누고, 모집 중만 보기 버튼은 유형 버튼과 같은 3열 한 칸 너비로 표시한다.

## 카드·버튼·드롭다운

- 메인 카드·버튼·드롭다운은 연한 베이지 배경·밤색 1px 테두리, 팝업 버튼은 크림색 배경·연한 베이지 1px 테두리다. 글씨는 고동색이다.
- 장학금 카드 모서리는 16px, 버튼·드롭다운 모서리는 12px다. 초기화·취소·적용 버튼에도 동일하게 적용한다.
- 마우스를 올리면 메인은 샌드 베이지, 팝업은 연한 베이지 배경으로 바뀌며 밤색 테두리를 사용한다. 테두리 두께를 바꾸지 않아 크기가 흔들리지 않게 한다.
- 키보드 포커스는 밤색 2px 외곽선으로 구분한다. 비활성 버튼에는 호버 강조를 적용하지 않는다.
- 팝업에서 선택된 옵션은 샌드 베이지 바탕·밤색 안쪽 테두리·굵은 글씨로 표시한다. 메인에 적용된 필터는 밤색 바탕·아이보리 글씨·굵은 글씨로 구분한다. 호버 중에는 메인은 샌드 베이지, 팝업은 연한 베이지 배경을 사용하며, 호버가 끝나면 선택 배경으로 돌아온다.
- 메인에 적용된 필터에는 제거 표시 `×`를 둔다.

## 스크롤

- 메인 목록과 팝업 본문은 폭 8px의 둥근 막대를 사용한다. 트랙은 투명하고 위아래 화살표는 숨긴다.
- 막대 기본 색은 연한 베이지, 막대에 마우스를 올리면 밤색이다.
- 외곽과 스크롤 영역 사이에 12px를 두어 둥근 테두리를 가리지 않게 한다.
- `scrollbar-gutter: stable`로 막대 유무에 따른 내용 너비 변화를 줄인다.
- 전용 스크롤바 선택자를 지원하지 않는 브라우저는 표준 `thin`과 밤색 막대·투명 트랙을 사용한다. 세부 모양은 브라우저에 따라 다를 수 있다.
- 오른쪽 설정 영역·선택 필터 내부의 보조 스크롤은 현재 브라우저 기본 형태다.
